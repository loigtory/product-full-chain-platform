# 62 号：预算 / 资源耗用报表（双账本 → API → 前端面板）

> 交接包：62（M3 验证链 · 预算/资源耗用报表）· 2026-09-19 · 提交前文档

## 目标

把分散的预算账本变成可审计的耗用报表：账本文件为唯一事实源，API 汇总现算不缓存，前端提供预算/资源耗用面板。

## 实现

### 后端

- `server/src/agent/worker.js`：settleTurn details 增加 `stage` / `tool` / `jobId`（按作业记录归属，新作业生效，历史 attempt 为 null）；
- `server/src/routes/agent.js`：新增 `GET /api/agent/budget`（owner 专属），覆盖**双账本**：
  - `ledgers.remediation`（active 账本，上限 8/2400s）；
  - `ledgers.exec`（host EXEC 账本，**上限 80/24000s**，用户拍板）；
  - 每个账本返回 `limits / usage / byStatus / byDay / byStage / recent(30 条脱敏)`；
  - `overall` 合并双账本 turns/seconds + EXEC 剩余；
  - 账本文件为唯一事实源，每次请求现算。

### 前端（原型工作台）

- `output/pfc-workbench-prototype/original/budget-panel.js`：自包含预算面板（header「预算」按钮打开）；
- `app.js`：header-right 注入「预算」入口；
- 面板展示：总体（总 turns/秒/EXEC 剩余）、双账本进度条（EXEC 80 上限百分比）、按阶段/按日期表、最近 EXEC 明细（含「执行流」入口，见 63 号）。

### 验收

`server/verify-62-budget-report.cjs`（11/11 PASS）：

- API 200 + 双账本结构 + exec 上限 80；
- API 汇总与账本文件独立重算一致（turns/seconds/byStatus）；
- `overall.turns = 双账本之和`；
- byDay 时间序列、recent 明细（attemptId 脱敏 `xxxxxxxx…`）存在。

浏览器实测（bu）：header「预算」→ 面板渲染（EXEC 14/80 18% · 499s · SUCCEEDED 14；Remediation 7/8 88% · 28s；明细表完整）。
