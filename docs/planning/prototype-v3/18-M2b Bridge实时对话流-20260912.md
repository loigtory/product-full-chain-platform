# 18-M2b Bridge 实时终端对话流（平台差异化核心）

> 定位：兑现最初诉求——「开发阶段调用 Zed/Codex/VS Code 等开发终端工具，并**实时跟踪开发终端的对话流**」。本轮打通 Bridge 双通道 WS：模拟 Bridge Agent（sim-bridge）以真实协议连接并逐行推送终端对话流，Web 端实时接收；无 Bridge 时 startRun 回退模拟（诚实标注）。
> 验证：`server\verify-m2b.mjs` 7 用例全绿（后端 + sim-bridge + Web 订阅全链路）+ M1 基线 18 / M2a 19 全绿 + 前端 m1-layer 6 / m1-e2e 8 全绿。

---

## 一、架构

```
浏览器工作台 ──REST──▶ 服务端（状态机/审批/审计）
      ▲                     │
      │  /ws/web?token=     │ job.start（runId/reqId/operation/plan）
      │  实时推送            ▼
      │                /ws/bridge?token=
      │  job.line ◀─────────┼── 本地 Bridge Agent（Zed/Codex/VS Code 会话代理）
      │  run.status         │   逐行推终端对话流 → job.snapshot → job.done
      │  bridge.status      │   30s 心跳（90s 无心跳 → 离线广播）
      └─────────────────────┘
```

## 二、协议（13 号文档第四节落地）

| 方向 | 类型 | 载荷 |
|---|---|---|
| 服务端→bridge | `job.start` | `{runId, reqId, operation, plan}` |
| bridge→服务端 | `job.line` | `{runId, cls, text}`（cls: cmd/info/ok/warn/error） |
| bridge→服务端 | `job.snapshot` | `{runId, stepNo, label, snapshotRef}` |
| bridge→服务端 | `job.done` | `{runId, exitCode}`（0→SUCCEEDED，否则 FAILED） |
| bridge→服务端 | `heartbeat` | 30s；90s 未心跳 → 离线 + 广播 |
| 服务端→web | `job.line` / `run.status` / `notice` / `bridge.status` | 增量实时推送 |

鉴权：WS query `?token=`（JWT，与 REST 同密钥）；`role:'bridge'` 才可连 /ws/bridge。

## 三、交付物

| 文件 | 说明 |
|---|---|
| `server/src/ws.js` | 双通道 WSS（noServer + 手动 path 分发——多 WSS 同 server 的已知坑）；心跳扫描；任务派发 |
| `server/src/routes/bridges.js` | POST /pair（签发 bridge_token）、GET /（Bridge 列表）、POST /heartbeat |
| `server/src/domain/service.js` | startRun：有在线 Bridge → 派发 job.start；无 → 回退模拟（诚实） |
| `server/sim-bridge.mjs` | 模拟 Bridge Agent（真实协议客户端）：心跳 + job.start 触发逐行推送 + snapshot + done |
| `output/.../original/ws-client.js` | 前端订阅层：job.line 追加 run.lines（终端面板实时滚动）、run.status、notice、bridge.status；断线 5s 重连 |
| `index.html` / `app.js` | ws-client 加载；api 模式 hydrate 完成后连接 /ws/web |

## 四、验证（verify-m2b.mjs，7 用例全绿）

pair 签发 bridge_token · Web 端收到 Bridge 上线推送 · **Web 端实时收到 5 条 job.line** · 内容为终端对话流 · job.done → run.status SUCCEEDED 推送 · Bridge 快照落库（replay ≥4 步）· 无破坏。

## 六、已知边界（诚实标注）

- **sim-bridge 是协议模拟器**：行为等价真实终端适配（Zed 插件/Codex CLI 包装器待开发），但行内容为模拟。
- 前端可见的实时滚动依赖**前端动作层切领域 API**（下轮 M2b-2）：当前 api 模式创建的 run 在领域层，前端状态树里尚无对应 run 时 ws-client 不渲染——种子 run 的推送可即时生效。
- WS 鉴权用 query token（生产建议子协议或首消息鉴权）。
- 心跳为进程内定时扫描，多实例部署需外置（M3+）。
