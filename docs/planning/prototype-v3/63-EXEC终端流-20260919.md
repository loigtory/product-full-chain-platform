# 63 号：EXEC 终端流（命令级输出流采集 → API 回放 → 前端终端查看器）

> 交接包：63（M3 验证链 · 终端流 UI）· 2026-09-19 · 提交前文档

## 目标

dev 阶段接入真实开发终端（codex/zed/vscode）后，作业命令的**逐块输出流**需要被采集、持久化并可回放，前端以终端样式实时查看真实作业输出（如 `node --test` 多行输出），不再只靠 AI 消息整体回写。

## 实现

### 后端

- `server/src/agent/command-runner.js`：`runCommand` 增加可选 `onChunk` 回调，stdout/stderr 逐块回调（采集失败不阻断命令）；
- `server/src/agent/exec-stream-store.js`（新）：ndjson 追加存储（`.local/pfc-exec-streams/<jobId>.ndjson`），jobId UUID 白名单 + 单块 64KB + 单作业 20000 块上限；`append / read / close`（exit 行闭合）；
- `server/src/agent/approval-service.js`：命令执行点接入 `onChunk` → 写流 + 命令结束写 exit 行（exitCode/timedOut）；
- `server/src/routes/agent.js`：
  - `GET /api/agent/requirements/:reqId/exec-stream?jobId=`（owner + agent_jobs 校验）；
  - `GET /api/agent/exec-stream?jobId=`（owner 宽松版，预算面板打开用）。

### 前端（原型工作台）

- `output/pfc-workbench-prototype/original/exec-stream-viewer.js`（新）：终端样式查看器（深色终端、stdout/stderr 分色、exit 元信息）；
- `budget-panel.js`：最近 EXEC 明细新增「执行流」列（新作业带 jobId 可点开）；
- `index.html` 引 exec-stream-viewer.js。

### 验收

`server/verify-63-exec-stream.cjs`（10/10 PASS，真实 EXEC 作业 `node src/hello.cjs`）：

- 消息完成 ok；`GET exec-stream 200`；
- 流块非空（3 块）、stdout 多行完整（line1/line2）、stderr 采集（err-marker）；
- exit 闭合 `{exitCode:0, timedOut:false}`；
- ndjson 文件落盘 + exit 行 + seq 连续（独立核对）。

浏览器实测（bu）：执行流查看器渲染真实三行输出（stderr 红色）+ `exit 0 · 3 块`。
