## 备注说明
### 关键假设
- 复用现有平台请求层（platformRequest）与既有组件库（Badge/Button/DataTableFrame），不重复造轮子。
- 后端接口（GET/PUT/DELETE 四路由）已随需求提供并联调，前端仅消费。
- 平台系数按 PC/Web 端 ×1.0。

### 不确定点
- 「skill 库全量浏览 + 一键加入」候选池（文档四-4）不在本需求范围，如追加需 +8H（浏览列表 + 搜索 + 加入交互）。
- worker 按配置装载（文档 2.4）为后端工作，前端无对应工时。

### 风险提示
- 三来源（本机/GitHub/公司）badge 与配置项来源字段强耦合，若后续新增来源需同步扩展类型定义。
- 编辑态副本合并逻辑（edits/newRows）状态分支较多，建议补充交互自测用例。
