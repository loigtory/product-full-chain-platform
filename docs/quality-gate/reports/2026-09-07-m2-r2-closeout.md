## 缺陷与回归

真实集成阶段发现并修复四项缺陷：

1. START_WORKSPACE_WRITE_RUN payload 重复携带外层 `runId`，违反 Bridge command schema。
2. Bridge 异常退出后已过期 LEASED start command 无法由同一 Bridge 回收，Run 会永久停在 STARTING。
3. Worker 对 class session 使用对象展开，丢失 prototype 方法，真实关闭时抛出 `session.close is not a function`。
4. 重启 Bridge 缺失内存 session 时把 VERIFY 映射为 REJECTED/FAILED，而正确语义应保持 UNKNOWN。

每项均先增加失败测试，再实现最小修复。聚焦回归命令：

`node --env-file-if-exists=.env.local node_modules/vitest/vitest.mjs run tests/unit/m2-r2-test-data.test.ts tests/unit/m2-bridge-worker.test.ts tests/integration/m2-agent-run-persistence.test.ts --maxWorkers=1`

结果：3 个文件、30 项测试 PASS。
