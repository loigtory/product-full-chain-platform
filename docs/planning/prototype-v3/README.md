## 三项核心判断

**产品主线已经明确。** 用户围绕一条需求连续完成澄清、文档、设计、执行和交付。跨需求清单、能力配置和审计分别进入产品空间、交付中心和治理中心，主工作区保持上下文连续。

**现有工程底座可以复用。** 代码已有生命周期、产物、评审、会话、作业、审批、Bridge 和 MCP 模块。主要工作是收口现有实现、补齐缺失业务事实，并将它们组合成原版的连续工作区交互；不需要因原型变化重选技术栈。

**首期完整范围继续保留。** 已确认的 `POD-PFC-001 / V0.1` 仍包含 5 个 CAP、26 个 Unit，按 M1–M3 交付。原型里的四个导航是信息架构，八个阶段是用户视图，都不改变 CAP/Unit 或 G0–G12 的定义。
