# Codex App Server protocol bindings

The adapter uses bindings generated by the installed and explicitly pinned Codex CLI. Generated files are source evidence and must not be edited by hand.

Current source:

- CLI: `codex-cli 0.153.4`
- Harness: `codex-app-server/0.153`
- Directory: `src/generated/app-server-0.153.4`
- Manifest: `app-server-protocol.json`

Regeneration on Windows uses two commands because passing every generated path to Prettier can exceed the Windows command-line length:

```powershell
codex.cmd app-server generate-ts --experimental --out packages\codex-adapter\src\generated\app-server-0.153.4
node node_modules\prettier\bin\prettier.cjs --write packages\codex-adapter\src\generated\app-server-0.153.4
```

After regeneration, review protocol changes, update the manifest count/hash, adapt the typed request surface, and run `npm run check:codex-protocol` plus the proportional gates. A newer installed CLI does not automatically authorize or activate a new harness version.
