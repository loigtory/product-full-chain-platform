## 实施前核实与设计

- WS 查找根级 runs 确实错误；本地 tick 会竞争推进服务端作业。
- 当前服务端缺少作业详情回读；离线模拟没有逐行 WS 事件。增加列表/详情回读，连接恢复时以服务端状态校正，不能靠浏览器猜测成功。
- 新建需求、确认版本与推进仍是本地动作。增加必要的领域动作衔接及版本草稿登记；保留原型已有的前端业务校验。
- 20 号所述 ID 无碰撞不能作为保证：实际种子存在 R-102 等低位编号。服务端分配时保留已有需求和嵌套作业编号，防止覆盖。
- API 操作采用异步互斥和可重试命令标识；领域 run 不再进入本地模拟质量门、核验或控制路径。实时行带序号去重；完成、断线、刷新均可回读。
- 终端保留双镜像与滚动位置；在尾部时跟随新输出，用户向上阅读时不强制滚到底部。明确显示模拟 Bridge / 服务端模拟 / 未核验执行来源。
- 后端监听显式绑定 127.0.0.1。仅使用已有依赖，不安装网络包。
