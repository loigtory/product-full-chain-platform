## 关键断言与独立证据

| 风险 | 本次实测 |
| --- | --- |
| 空库 / 快照旁路 | PG 首屏无需求，不上传 factory；PUT/DELETE state、batch 拒绝 |
| 版本 / 身份 | HTTP 创建后跨进程原样恢复；回答生成版本；旧 revision 冲突；配置角色不可用 body.role/by 提权，跨租户相同 publicId 隔离 |
| 原件 | 单文件恰好 10 MiB 可保存、超限拒绝；20 个及 50 MiB 逻辑边界；二进制不假解析；同 hash 去重，下载 SHA 与独立磁盘一致 |
| 文件失败 | 不可用目录及材料写入故障；无成功元数据或收据半写，独有原件清理、共享原件保留；路径穿越及跨租户下载拒绝 |
| 会话 / UI | 附件、模拟回复、停止/重发关系、Diff 采纳，浏览器/服务重启后保留；旧消息使用历史原件版本；100 条分页、图片解码与 URL 回收、断网重试/草稿恢复 |
| 执行 / 事件 | 未批计划不能启动；同 commandId/dispatch 不重复派发；受控 Bridge 行、回放、模拟质量记录成功；205 行历史分页；取消晚到 done 不翻终态；重启 UNKNOWN、租约 lost |
| 事务 / 配置 | 同 key 改内容冲突；两人抢租约一胜一冲突；个人通知已读隔离；回滚事件不存在；SQL 锁超时后原命令重试；缺配置/坏端口/坏 checksum/列/约束拒绝 |
| 模式 / 视觉 | local/mock/memory 回归；三档 PC 无文档横向溢出；原三栏、双终端和键盘输入保持；模拟标识及未接入入口可见 |
