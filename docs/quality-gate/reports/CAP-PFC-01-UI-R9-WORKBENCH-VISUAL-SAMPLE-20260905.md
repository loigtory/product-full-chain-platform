## 2. 实施范围

- 为 `GlobalHeader` 和 `PageIntro` 增加共享 `compact` 密度变体，默认变体保持不变。
- 需求工作台采用 56px 顶栏、1320px 居中工作区和 24px 工作台标题。
- 把需求范围、搜索和视图切换合并到同一工作栏，减少标题区与数据区之间的断裂。
- 保留 PC 运营表格，不复制参考站的营销首屏和内容发现卡片墙。
- 列表不再直接展示长技术 ID；完整 ID 仍通过名称控件的 `title` 属性保留，便于核对。
- 本地体验账号显示友好名称“全权限体验账号”，原始账号 ID 仍通过单元格 `title` 属性保留。
- 中文字体栈优先使用 `Segoe UI Variable Text`、`Microsoft YaHei UI` 和 `PingFang SC`。
