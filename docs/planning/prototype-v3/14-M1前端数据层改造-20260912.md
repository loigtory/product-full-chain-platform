# 14-M1 前端数据层改造（前端先行 · 第一步）

> 目标：把已验证的交互原型（`output/pfc-workbench-prototype`）改造为**可接正式后端的正式前端**，第一步完成**数据层适配器**。交互层零改动，原型 6 组回归保持全绿。
> 配套：《12-正式平台服务端设计蓝图》《13-M1接口清单与开发说明》《m1-schema.sql》。
> 边界（如实）：本期 mock 为同步内存态（模拟服务端），api 为**桥接骨架 + 契约映射**，真实后端联调在 M1 后段。

---

## 一、三模式数据层

| 模式 | 存储通道 | 用途 | 数据隔离 |
|---|---|---|---|
| `local`（默认） | 浏览器 localStorage 直通 | 原型基线行为，回归等价 | `pfc.prototype.original.guide.v1` |
| `mock` | 同步内存态 + 可选持久化（独立 key） | 模拟服务端：无基线 key 依赖，刷新可保留 | `pfc.prototype.mock.v1` |
| `api` | `PFCAPI.api` 内存镜像 + 变更队列 | M1 后段接真实后端（fetch 按 13 号契约） | 服务端库（`m1-schema.sql`） |

统一接口与 `localStorage` 同构：`{ getItem, setItem, removeItem }`——`model.js` 只通过 `PFCStore.active()` 访问，动作层（actions / model 状态机）零改动。

**切换机制**：页面加载前设 `window.PFC_DATA_MODE`（优先）→ 否则读持久化选择 `pfc.prototype.dataMode` → 默认 local。header 徽标点击循环切换并重载（`A['data-mode']`）。

## 二、改造点清单

| 文件 | 改动 |
|---|---|
| `original/data-layer.js`（新增） | `PFCStore`：local / mock / api 三 store + active()/setMode()/cycle()/label() + 模式持久化 |
| `original/api-client.js`（新增） | `PFCAPI.api`：getSync/setSync/removeSync（同步表面 + 变更队列）、req()（fetch 客户端骨架）、contract()（13 号契约清单） |
| `index.html` | 加载顺序：data.js → **data-layer.js → api-client.js** → model.js |
| `original/model.js` | 5 处 `localStorage` → `STORE()`（动态取 active()）：加载 / storageBase / checkRevision / save / reset |
| `original/app.js` | header 加 `.data-mode-tag` 徽标（当前模式，点击切换） |
| `original/actions.js` | `A['data-mode']`：cycle + toast + reload |
| `original/guide.css` | `.data-mode-tag` 样式（虚线徽标，hover 高亮） |

设计要点：`STORE()` 每次动态取 `active()`，同一会话 setMode 后读写立即生效；vm 回归环境（无 `PFCStore`）回退 `localStorage`，行为不变。

## 五、M1 后段（下一步，后端就绪后）

1. **P.init 异步化**：api 模式首次加载由同步 `getItem` 改为首屏 `fetch`（GET /api/reqs + /api/knowledge + /api/caps + /api/notices），组装 `P.s` 后渲染。
2. **增量同步**：`PFCAPI.api.flush()` 把变更队列批量提交 `/api/batch`（后端按 13 号事务化），失败回滚到 pending 并提示。
3. **鉴权接入**：dev-login 换 token（`PFC_API_TOKEN`），401 统一跳登录。
4. **通知订阅**：WS `/ws/web` 推送未读计数（对齐 13 号第七节），替换轮询。
5. **模式矩阵收敛**：联调通过后默认切 `api`，local/mock 保留为演示/离线通道。

---

## 六、已知边界（诚实标注）

- mock 为**同步模拟**，无网络、无真实服务端事务；持久化仅本机。
- api 模式本期为骨架：`req()`/`flush()` 已定义但未接 UI，接入需先完成后段第 1-2 步。
- 模式切换经 reload 生效（`PFC_DATA_MODE` 页面级设置可免 reload）。
