## 布局与页面模板

顶部导航高 52px；四入口、全局搜索和原型场景入口保持同一横排。工作区左栏 252px、右栏 368px，中央弹性扩展，各内容区独立滚动。工作区最小 PC 宽度为 1120px；移动端与较小屏幕改版不在本次范围。

中央按“阶段提示 → 结构化问题/文档/任务 → 同需求对话”组织。底部保留门禁阻断与下一步、输入框；右侧终端/画布/证据是同一需求的不同视图。开发页保留中央 Zed 镜像与右侧终端，不能因信息相似而删除用户已认可的双端观看方式。

工作台采用待办、运行恢复、Agent 简报与最近需求，内容从当前演示记录汇总。产品空间和交付中心以表格为主，治理中心以能力条目和配置表为主；不用营销页的装饰区域替换密集操作内容。

新增弹窗沿用白色表面、原色按钮、字段标题与错误区；长文和 Diff 使用更宽阅读面。列表、详情和工作区统一来源标记和状态语义，已确认但受上游影响的文档显示“需重新评审”。

## 交互状态与适配

| 交互             | 本轮表达与证据                                                             |
| ---------------- | -------------------------------------------------------------------------- |
| 导航与选中       | 查看阶段和实际阶段分别标注；后退恢复 URL 指定对象；四入口保持上下文        |
| Hover / Focus    | 导航与表格浅底反馈，按钮边界和键盘焦点可见；Tab/Esc/方向键按对应控件工作   |
| 输入             | 按需求保留草稿；中文组合输入不发送，Shift+Enter 换行；模态焦点保持在弹窗内 |
| 加载 / 失败 / 空 | 场景入口可重现；加载有状态，失败可重试，空空间可创建第一条需求             |
| 禁用与只读       | 关键推进按钮带原因；只读写入被拦截；样式禁用不作为正式鉴权                 |
| 版本冲突         | 保存时保留正在编辑内容，提示比较最新版本；不会覆盖已确认历史正文           |
| 作业控制         | 请求取消先等待确认；UNKNOWN 引导核验；两处终端同步，状态与退出码分开       |
| 动效             | 沿用运行光标和轻提示；不引入全屏过渡；正式接入须支持减少动效偏好           |

自动布局读回：三档宽度均无根节点横向溢出，header 高度52px，图标最大宽度不超过32px。已查看代表截图核对三栏、终端、画布、治理条目与发布失败提示；正文和主操作未相互遮挡。

[计算样式读回](../../output/pfc-workbench-prototype/evidence-guide-20260911/visual-readback.json) 确认左栏252px、右栏368px；中央在1280/1440/1920下分别为660/820/1300px。正文14px、行高21.7px；卡片白底、边框rgb(232,237,242)、圆角8px；终端底色rgb(15,23,42)，与原版样式一致。

局限：尚未进行真人操作计时、屏幕阅读器验收、多浏览器兼容性和精确色差验收；原版辅助文字较小，正式 token 映射时需结合可读性确认，不能用“自动通过”代替视觉结论。保存的失败流程截图可能包含快速自动操作产生的暂态提示堆叠，实际提示按原型计时消失。
