## 1. 范围与验收边界

UI-R11 只修改独立体验页 `/ui-preview/workbench`、共享 UI token/模板和 `/ui-kit`。正式 `/`、业务 API、数据库结构与业务数据均未修改。本轮没有提交、推送、部署、发布、迁移或数据库写入。

工程 PASS 表示约定的排版密度、交互回归、安全边界和项目 Full Gate 已通过；不代表产品负责人已经确认主观视觉，也不代表正式页面已经迁移。

## 3. 实现与复用模板

- 三层 token：primitive -> semantic -> component，固化字体、字号、字重、行高、控制高度、表头/行高和内容宽度。
- 共享模板：`PageIntro` 图标槽、`SummaryGrid`、`SummaryPanel`、参考主题下的 `GlobalHeader`、`MetricCard`、筛选控件与 `DataTableFrame`。
- 元素目录：`/ui-kit` 展示并直接运行上述共享模板，后续页面不得自行发明同类视觉值。
- 数据边界：体验页只调用现有 GET 列表和详情接口；概览与摘要均从当前返回结果计算。

发布、部署和正式页迁移均未授权。后续只有在产品视觉验收通过、责任人登记完成并确认正式页迁移设计后，才能进入下一版本；发布仍需单独确认制品、环境、负责人、回滚、smoke、观察窗口和监控。

## 9. 轻量复盘

- 返工来源：此前只模仿颜色和标题，没有把参考站计算样式、信息密度和导航规划作为可执行契约。
- 本轮修正：同浏览器读取真实样式 -> token 化 -> 共享模板 -> 独立预览 -> 计算样式断言 -> 三视口对照。
- 后续规则：新增或迭代页面必须复用 `/ui-kit` 模板；偏离 token 或模板时要先记录业务原因和产品确认，不再凭页面作者主观决定粗细、字号、颜色和密度。
