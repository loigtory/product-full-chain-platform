## 1. 范围与边界

UI-R12 将正式 `/gate-center` 和 `/material-library` 迁移到 UI-R11 已确认的排版、密度、导航和配色模板。需求工作台 `/`、需求详情、弹窗/抽屉、业务 API、后端行为、数据库结构与业务数据均未修改。

本轮没有提交、推送、部署、发布、迁移或外部环境写入。工程 PASS 不代替产品负责人的视觉验收，也不构成发布授权。

## 2. 架构与复用

- `App.tsx` 只装配路由和跨页状态；两个中心页面位于独立 feature 目录。
- 门禁中心拆为页面控制器、筛选模型和表格视图；材料库拆为页面控制器、筛选模型、筛选视图和表格/引用视图。
- 共用纯数据和函数位于 `operations/model.ts`，共用 React 状态组件位于 `operations/shared.tsx`，避免 Fast Refresh 与业务模型混杂。
- 页面文件最终为门禁 `328` 行、材料 `254` 行；架构测试要求独立路由页少于 `350` 行，并锁定前端页面边界和后端 route/application/repository 分层。
- `AGENTS.md` 已明确：独立路由页必须独立 feature 目录；前端装配、交互、领域逻辑分层；后端 transport/application/domain/repository 分层。

## 3. 视觉与交互契约

- 共享参考主题：65px 顶栏、30/36/700 页面标题、Noto Sans SC 优先字体栈、白色工作画布和低对比边框。
- 页面结构：一级导航、业务标题区、二级视图导航、两个 130px 摘要面板、32px 筛选工具栏、工作面板与数据表。
- 表格密度：40px、14/20/500 表头；56px、14/20/400 双行运营数据行。
- 门禁中心保留当前/历史、阶段、状态、模式、刷新、详情往返和筛选记忆。
- 材料库保留全部/待确认、状态、来源、用途、敏感级别、引用展开、影响处理、刷新和筛选记忆。
