# PFC 工作台交互原型 V3

## 本轮范围

用户已要求以现有原型继续完善原型；平台系统迭代仍暂停。本轮仅编辑此原型目录，保留 `index.html`，新增 `index-v3.html` 及其专用样式、演示数据、交互脚本和验证脚本。无依赖安装、数据库、真实 AI/工具调用、提交或发布。

保留原型的任务型首页、中央对话、左侧阶段上下文、右侧成果/工具、蓝白视觉。先修复已复现的问题，再补足同一需求的工作连续性；不扩展为完整平台实现。

## 实施计划

1. 记录基线，先复现“停止被显示为完成”的失败检查。
2. 将查看阶段与实际阶段分开；需求切换、材料、草稿、执行记录和证据使用同一需求数据。
3. 实现问题回答、草稿查看/修改/确认、停止/继续演示、阶段推进前置条件和浏览器本地恢复。
4. 完善能力目录、阶段绑定与本次临时装载的独立状态；所有动作仍为演示。
5. 实现 1280/1440/1920 桌面布局、上下文抽屉、画布聚焦、键盘与中文输入支持。
6. 运行定向浏览器回归，查看截图并自审；交付原型入口和验证结果。

## 验证与数据

- 数据全部沿用/扩展原型中的虚构需求。浏览器状态仅保存到原型专属 `pfc.prototype.v3` key。
- 验证使用独立临时浏览器上下文，输入前缀 `CODEx_TEST_PROTOTYPE_V3`；不访问原有平台 API、数据库或外部网络。
- 覆盖停止语义、阶段浏览、需求隔离、画布/证据关联、刷新恢复、草稿版本确认、能力绑定、中文输入、键盘和三宽度呈现。
- 验证浏览器在 finally 中关闭；截图和验证输出留在系统临时目录，可在复核后清理。
- 回滚：关闭 V3，继续打开未改动的 `index.html`。删除演示数据只影响 V3 专属存储。

## 交付状态

V3 已完成本轮交互完善及定向浏览器验证。直接用 Edge 打开 [index-v3.html](index-v3.html)，无需启动平台服务；原版 [index.html](index.html) 保留用于对照。请保持入口、CSS 和两个 JavaScript 文件在同一目录。

建议从首页的“保单到期提醒”开始：回答问题 → 确认草案 → 修改并确认需求文档 → 确认设计 → 分步模拟开发 → 模拟测试 → 核对验收清单 → 批准并单独执行模拟发布 → 记录复盘。也可以用“会员积分过期提醒”体验停止/继续，或用“理赔材料清单重构”体验文档阅读与验收。

本轮补齐：

- 首页待办随实际状态变化，已完成事项移出待办；产品空间与交付中心可返回对应需求。
- 查看阶段与实际推进分离；未来阶段只读，阶段推进检查前置条件。
- 草稿支持修改、新版本、字段对比、正文阅读、聚焦阅读及确认；确认后保留版本。
- 停止任务保留进度与步骤；开发使用“模拟完成下一步”推进，避免后台自动跑完影响阅读。
- 需求、文档、任务与证据同源；需求、阶段、结果标签、文档版本和聚焦模式写入 URL；操作与未发送输入保存在本浏览器。
- 全局能力启用、阶段默认绑定和单需求会话临时选择分开，互不冒充。
- 1280 桌面使用可关闭的上下文抽屉；1440 / 1920 保留三栏，宽屏对话和卡片对齐。修复图标尺寸，支持中文组合输入、换行、键盘标签切换与弹窗返回焦点。

验证结果详见 [V3-验证报告.md](V3-验证报告.md)。原型功能验证通过，视觉已做截图自检，用户体验与视觉确认待用户查看。

归属为 POD-PFC-001 的原型评估工作；本轮不新增 M1/M2/M3 里程碑或 CAP/Unit 实现结论。原型实现为 LOCAL_VERIFIED；平台真实集成未执行，平台验收和发布未执行。平台系统迭代及原有下一路由保持用户要求的暂停状态，后续先收集 V3 原型反馈。

所有本轮测试浏览器均已关闭，无新增常驻服务。数据保留在用户主动打开 V3 的浏览器中，可通过首页“重置演示”清除本原型记录。
