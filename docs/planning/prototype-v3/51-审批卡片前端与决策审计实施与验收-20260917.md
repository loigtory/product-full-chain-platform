# 51-审批卡片前端与决策审计实施与验收-20260917

> 承接：50 号「审批流命令执行控制」待办第 1 项（前端审批卡片 UI）+ 交互式审批（计划外命令从立即 DENIED → PENDING 待 owner 决策）。
> 状态：**已实施，单元+集成+HTTP 闭环验收通过；前端卡片已在浏览器确认渲染**。本轮改动**未提交 git**（与 50 号一并待确认提交）。

## 一、背景与决策

- 50 号已落地服务端审批流执行器（command-runner 五层安全模型）与命令工具接线，但计划外/敏感命令为**立即拒绝**（dispatch 直落 DENIED）。
- 51 号目标：计划外命令（TOOL_OUT_OF_SCOPE / COMMAND_NOT_IN_PLAN）从**立即 DENIED** 改为**交互式 PENDING**，在聊天消息流内嵌审批卡片，由 owner 在界面 approve/deny，触发既有 `decide` API；并补齐**决策审计事件**（此前 deny 用例断言取到的是 PENDING 创建事件，暴露决策事件缺失）。

## 二、实施内容

### 2.1 后端：计划外命令走交互式审批

`server/src/agent/approval-service.js`（dispatch）：

- 拒绝分支由「仅 TOOL_OUT_OF_SCOPE 走 PENDING」扩展为 **TOOL_OUT_OF_SCOPE 与 COMMAND_NOT_IN_PLAN 均走 PENDING**（deny 规则命中仍立即 DENIED）；
- 工具响应 `toolResponse=false` 带 `{ code, approvalId, requiresNewPlan:true }`，模型据此向 owner 请求计划外授权并入执行计划。

### 2.2 后端：决策审计事件

`server/src/persistence/agent-approvals.js`（decide）：

- approve/deny 落库后追加写 `agent_events` `type='approval'`，payload `{ approvalId, scopeHash, state:updated.state, decidedBy }`；
- **修复的真实缺陷**：此前 deny 用例断言「agent_events 最新一条为 approval 事件」时取到的是 dispatch 创建时的 PENDING 事件而非决策事件——现在决策事件独立落库，审计可回溯「谁在何时如何决策」。

### 2.3 后端：exec-control 错误可诊断性修复

`server/src/agent/exec-control.js`：

- `fail()` 默认补 `status: 409`——此前所有 exec-control 校验失败（如 `WORKSPACE_NOT_AUTHORIZED`、`PLAN_BASELINE_CHANGED`）不带 status，被统一错误处理**降级为 503 STORAGE_UNAVAILABLE**，掩盖真实原因；
- 修复后 approve 无 workspace 返回 **409 WORKSPACE_NOT_AUTHORIZED**（已 HTTP 验证）。

### 2.4 前端：消息流内嵌审批卡片

`output/pfc-workbench-prototype/original/domain-conversation.js`：

- 新增 `approvalBanner(id)`：进入工作区后 GET `/api/agent/requirements/:reqId/tool-control` → 过滤 PENDING → 渲染 `.pfc-approval-banner` 审批卡片（工具名 / 范围 / 固定命令 / 状态 / 哈希前 16 位 + 「同意范围（需新计划）/ 拒绝」按钮）；
- 按钮走既有 `host-tool-decision` remote（POST decision API）；决策成功后追加 `P.render({quiet:true})` 刷新卡片状态；
- `P.render` 包装：仅 `V.pg()` 页面时 setTimeout 80ms 拉取一次。

`output/pfc-workbench-prototype/original/base.css`：新增 `.pfc-approval-banner` 系列样式（黄色渐变、边框、按钮组）。

## 四、行为变更说明

| 项 | 50 号（旧） | 51 号（新） |
| --- | --- | --- |
| 计划外命令 | dispatch 立即 DENIED（直接拒绝） | PENDING 交互审批，owner approve 后并入执行计划 |
| 决策审计 | 无独立决策事件（仅创建事件） | approve/deny 后写决策 agent_events |
| exec-control 失败 | 无 status → 被降级 503 STORAGE_UNAVAILABLE | 409 + 明确 code（可诊断） |
| 前端 | 无审批入口 | 消息流内嵌审批卡片（approve/deny 按钮 + 决策后刷新） |
